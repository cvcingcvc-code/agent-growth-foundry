# 数据 / 安全 / 商业使用准则

- GitHub 公开不等于可复制和出售。源码、教程正文、模型权重、数据集、图片和依赖分别核查授权。
- `MIT`、`Apache-2.0` 不代表自动可发布；版权声明、NOTICE、依赖许可与第三方素材仍需确认。
- `GPL/AGPL` 等要求单独审查；无许可、NC 或来源不明默认阻断商业交付。
- 训练数据接受 `self_authored` / `explicit_training_permission` / `licensed_for_training`，附来源、审批与人工审阅者；示例标注 smoke。
- 不能自动抓取外部模型回答用于训练，除非服务条款及权利均允许。绝不存储密钥、密码、个人信息。
- 用去重及固定 eval 留出集避免数据泄露；指标记录样本数、基线、实验配置和统计局限。
- 模型输出不能作为事实/授权唯一依据；训练小模型不可自行批准许可证与商业发布。
- 数据、权重与 checkpoint 不提交到公开仓库；本机保存并可审计地备份。
