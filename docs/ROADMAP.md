# 长期方向冻结 / Roadmap

**Vision**: Agent Growth Foundry = 持续学习、合规采集、产品生产、模型改进的双轨自成长系统。

## Track A: 产品工厂（从第一天持续推进）
- A0：建立可审计来源、版权过滤、候选队列、交付流水线。
- A1：连接已有 GitHub 教程采集项目，读取其 SQLite 和候选记录，仅增量对接，禁止清库。
- A2：选出 3 个可获许可的候选产品，做出 1 个原创增值资料或可运行工具。
- A3：自动构建、测试、修复三轮内、生成用户试用包；人工审核后再发布。

## Track B: 本地模型（与 A0 同一天启动）
- B0：在任何 CPU 环境跑真正的参数训练与 checkpoint 恢复测试（能力有限，仅管线烟测）。
- B1：Windows NVIDIA GPU 环境用 Qwen3-0.6B + PEFT/LoRA 做首轮真实微调和验证。
- B2：积累经审查、许可允许、去重且标记来源的样本，比较 SFT 模型与基础模型在隔离评测集上的表现。
- B3：专属小模型承担低风险模块，如候选分类/初审辅助，关键审查规则仍由确定性规则+人工负责。
- B4：用外部 Agent 提炼“难题—解决过程—实测反馈”，只将核实的样本进入训练集；模型升级必须通过回归指标。

## V1 验收冻结
- 软件：离线示例完成候选入库、许可证门控、持久日志与报告。
- 训练：有实际 checkpoint、损失与基准指标，能二次加载推理（CPU 烟测）；本机 GPU LoRA 脚本已提供但未运行不能记 PASS。
- 完成之前不做商品自动发布、支付、无限自循环或生产环境部署。

## 非目标
- 无人监督无限自我训练；抓取无许可资产直接出售；将第三方 API 对话未经许可用于蒸馏；指标不经过测量就写“性能提升”。
