# 长期方向冻结 / Roadmap

**Vision**: Agent Growth Foundry = 持续学习、合规采集、产品生产、模型改进的双轨自成长系统。

## V1 已完成 ✅（2026-10-21 验收通过）

### Track A: 产品工厂
- ✅ A0：建立可审计来源、版权过滤、候选队列、交付流水线。
- ⬜ A1：连接已有 GitHub 教程采集项目（REST 完成，GraphQL 未实现，保持开放）。
- ✅ A2：选出 3 个可获许可的候选产品，做出 1 个原创增值资料。
- ✅ A3：自动构建、测试、修复三轮内、生成用户试用包（publish_enabled=false）。

### Track B: 本地模型
- ✅ B0：CPU 环境真正参数训练与 checkpoint 恢复测试。
- ✅ B1：Windows NVIDIA GPU 环境 Qwen3-0.6B + PEFT/LoRA 首轮微调和验证。
- ✅ B2：积累经审查样本，比较 SFT 模型与基础模型在隔离评测集上的表现。
- ⬜ B3：专属小模型承担低风险模块（尚未达到可用水平）。
- ✅ B4：用外部 Agent 提炼实测反馈，核实样本进入训练集。

### V1 验收冻结
- ✅ 软件：离线示例完成候选入库、许可证门控、持久日志与报告。
- ✅ 训练：有实际 checkpoint、损失与基准指标，能二次加载推理。
- ✅ 安全：sandbox_runner 三层隔离 + exec_gate 执行级门控 + 150/150 测试通过。

## V2 方向冻结（2026-11-23 冻结）

**目标**：从工程骨架到「可用模型」。

**详细规范见 [`docs/DEVELOPMENT_PLAN_V2.md`](DEVELOPMENT_PLAN_V2.md)**

**V2 验收标准**：
1. 固定 50 题编码回归集上 pass@1 ≥ 50%
2. 本地推理 CLI 多轮对话 ≥ 3 轮
3. HTTP API 服务（OpenAI 兼容）
4. 训练数据 ≥ 2,000 条
5. 至少 1 次冠军换代

**阶段路线**：

```
Phase 0 (Bug 修复) → Phase 1 (数据 136→620+) → Phase 2 (训练升级+首次换冠)
                                                        ↓
                     Phase 4 (CI/CD+调度) ← Phase 3 (API+UI) → Phase 5 (模型跃升)
```

## 非目标（V1 + V2 通用）

- 无人监督无限自我训练；抓取无许可资产直接出售；将第三方 API 对话未经许可用于蒸馏；指标不经过测量就写"性能提升"。
- 自动付费/自动发布/自动变现（V2 范围内不开放）。
- 生产环境多用户并发服务。
